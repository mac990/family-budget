☁️ 雲端同步（Google 試算表）

📋 第一次設定：步驟與 Apps Script 程式碼
  1. 瀏覽器開 sheets.new 建立新試算表，命名「家庭還款」。
  2. 上方選單「擴充功能」→「Apps Script」，刪掉原有內容，貼上下方程式碼，把第一行 TOKEN 改成你們家的密碼，按儲存。
  3. 右上「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」→ 執行身分「我」→ 具有存取權的使用者「所有人」→ 部署 → 完成 Google 授權。
  4. 複製出現的「網頁應用程式網址」（結尾 /exec）貼到上方欄位，密碼填相同，按「儲存並連線」。
  5. 其他家人用手機開同一個 App 網址，填同樣的網址與密碼即可同步；也可以直接打開試算表的「總覽」分頁看資料。
⚠️ 之後若修改 Apps Script，需「部署 → 管理部署作業 → 編輯 → 版本：新版本」才會生效。同步採「最後存檔者為準」，請避免兩人在同一分鐘內同時改同一筆。
